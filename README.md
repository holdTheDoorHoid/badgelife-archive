# Badgelife Archive

A community-maintained historical archive of conference badges and SAOs (Shitty Add-Ons):
what each one is, who made it, what it does, what it cost, how it was distributed, and, where the
files exist, how to make your own. Live site: **https://holdthedoorhoid.github.io/badgelife-archive/**

This is a fork of the [badge.life](https://badge.life/) website ([badgelife/website](https://github.com/badgelife/website))
run by the Badgelife Village. It is not affiliated with the village or DEF CON; see the site's
[About](https://holdthedoorhoid.github.io/badgelife-archive/about/) page for credits, research
method and takedown policy.

## Layout

| Path | What |
|:--|:--|
| `_badges/<event>/<slug>.md` | One entry per badge or SAO. Structured front matter + prose body. **The source of truth.** |
| `_data/events.yml` | Events (DEF CON 24…34, Supercon, camps…) that entries belong to. |
| `badges/<event>/index.md` | Per-event listing pages (generated by `scripts/gen_event_pages.py`, body editable). |
| `badges/index.md` + `assets/js/archive.js` | The faceted search UI, reading `assets/data/badges.json`. |
| `assets/data/badges.json` | Search index, generated by `scripts/build_index.py` (also validates entries; CI runs it). |
| `assets/images/badges/<event>/<slug>/` | Photos, credited in each entry's `images:` list. |
| `docs/research-guide.md` | The rules for filling in an entry: no guessing, cite everything, controlled vocabularies. |
| `data/` | Sheet exports, stub records and intake results the entries were generated from. |
| `scripts/` | Import, generation, validation, image fetching and Wayback archiving tools. |

## Building locally

Ruby 3.2+, Bundler 2.5.x, Python 3 with PyYAML (and Pillow for `fetch_image.py`).

```bash
bundle install --path vendor/bundle
python3 scripts/build_index.py          # validate entries + write the search index
bundle exec jekyll serve                # http://localhost:4000/badgelife-archive/
```

## Contributing

Fix or add an entry by editing its file (each page has an "Edit this page on GitHub" link), or open an
issue from the "Open an issue" link at the bottom of any entry. Full field reference:
https://holdthedoorhoid.github.io/badgelife-archive/contributing/

Makers: photos and contact details are reproduced with credit from public sources; ask for changes or
removal in an issue and it will be done.
