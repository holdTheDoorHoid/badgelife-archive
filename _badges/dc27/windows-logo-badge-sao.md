The Windows Logo Badge SAO is a shitty-add-on (SAO) made by TeamID64F (Tindie seller s3gfault) for DEF CON 27 in 2019. It reproduces the classic Windows 95 four-pane flag icon, with each pane rendered in its original color, and a set of LEDs that light up the trailing edge of the logo when the SAO is powered by a host badge.

The maker sold it on Tindie for $10 as an unassembled kit, warning that builders would be soldering components as small as 0402 — "fun and frustrating for the whole family." The listing notes that a fully-assembled version, once offered, was discontinued (joked as being retired along with Windows XP-era support). The product is no longer listed for sale on Tindie. No public repository, schematic, or bill of materials for the design was found, and the maker did not state the MCU (if any), exact LED count/type, or production quantity.
