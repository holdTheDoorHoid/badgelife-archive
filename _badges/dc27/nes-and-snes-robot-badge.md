The NES and SNES Robot Badge was a project by Hackaday.io user "true," conceived as an entry for DEF CON 27 in 2019. It combined two ideas in one badge: a nametag built around a 0.91" 128x32 OLED display, and a small functional robot, controlled by a PIC32MX250F128B alongside an ATMEGA328PB-AU handling touch input and LEDs, that could physically replay recorded button presses to play NES and SNES games.

The maker described it as an interactive soldering kit and said they intended to release full source code, schematics, and an assembly guide, with some units eventually offered for sale to help fund related projects. None of that materialized on the public project page: the build log shows the project stalled and was ultimately shelved before DEF CON 27, with no completed prototypes, pricing, or distribution plan ever finalized.
