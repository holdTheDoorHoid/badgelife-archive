The Skully badge is a skull-shaped PCB art badge made by Nick Pisarro for DEF CON 27 in 2019, in a run of roughly 125 pieces. Its defining trait is a one-sided circuit layout: rather than routing traces on both faces, Pisarro kept the wiring to a single side so the skull artwork on the board itself would read cleanly, without circuitry interrupting the design. It was worn like a pin, with commodity project pins glued to the back rather than a dedicated attachment mechanism.

The badge was covered in Hackaday's pictorial roundup of DEF CON 27's unofficial badge scene, which is the only detailed account of it found during this research pass. No maker storefront, price, distribution method, chip, LED, or display information turned up, and no schematic or firmware files were found, so those fields are left empty rather than guessed.

One loose end: a secondhand eBay listing for what appears to be the same badge - also citing a 125-unit run - labels it a "DEF CON #24" item instead of DC27. That listing's own page could not be loaded (it returned an error), only a search-result snippet, and eBay sellers frequently get con years wrong on resale listings, so this entry keeps the DC27 attribution from Hackaday's contemporaneous coverage. Anyone revisiting this entry should watch for a primary source that settles which DEF CON year the badge was actually made for.
