"SAO Ninja Baby" is a two-piece shitty add-on (SAO) set made by sqearlsalazar for DEF CON 27 (2019), sold as a single $32 listing on Tindie. The main piece is a white-and-gold, robot-suit-shaped SAO the maker calls "Ninja," which lights up with two slow-blinking RGB LEDs for eyes and two fast-blinking RGB LEDs for a mouth, giving it a simple blinking "face." It can run off its own included coin cell battery or draw power from a compatible DEF CON 26 or 27 main badge. Bundled with it is a smaller, separately pre-assembled gold robot-shaped SAO the listing calls the "baby," which the description does not credit with any lights of its own.

The Ninja SAO uses the 1.69bis-style 6-pin (2x3) connector, and the listing notes that a male and a female connector are included but must be soldered on by the buyer to mount it (the maker offered to pre-solder them on request). It also ships with a pin and clutch so it can be worn on its own, like a pin, independent of a host badge. The bundled baby SAO comes with its male 2x3 connector already soldered, and can be powered either by a compatible host badge or by the Ninja SAO once its own connector is soldered.

The Tindie listing for this item is retired ("no longer available for sale" / discontinued), with no quantity made disclosed. No design files, firmware, or open-source hardware repository were found for it.
