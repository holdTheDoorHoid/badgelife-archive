BadgePirates made this sheriff-star-shaped party badge for the SecKC crew's gathering at DEF CON 27 in 2019. The design is a gold-plated star on black PCB with lights built into the star's points. The GitHub repo's promotional artwork is filed as an "SAO" banner, but the maker's storefront and repo describe it as a standalone party badge/keepsake rather than a plug-in SAO.

The hardware files (KiCad schematic, PCB layout, footprints, and documents, but no firmware) are published on GitHub; the repo is archived and gives no further build narrative. In 2021, BadgePirates resold a small remaining stock of these badges on Tindie at $4.99 each — some non-working assembled units, some bare unpopulated boards — as leftovers found in storage, rather than as new production.

This entry duplicates dc27-seckc-defcon-party-badge-sao, an already-researched entry for the same item; see that entry for the fuller writeup and fact-check history.
