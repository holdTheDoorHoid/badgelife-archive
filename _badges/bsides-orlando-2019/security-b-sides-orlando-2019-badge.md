The Security B-Sides Orlando 2019 Badge is a buildable badge project by Jonathan Singer (hackaday.io/jonathan-singer), built around a Digispark USB development board (ATtiny85-based) driving an 8x8 LED matrix module through a MAX7219 driver chip. The maker describes it simply as "a fun buildable project for attendees," suggesting it was intended as a hands-on solder-it-yourself build rather than a pre-assembled giveaway.

The project's Hackaday.io page hosts open Gerber files (silk, copper, and board outline layers, nine files in all, uploaded April 2019), making the PCB design reproducible, though no firmware repository or bill of materials was linked from the page. No pricing, quantity, or distribution details were published, and no secondary coverage (press, forum posts, or storefront listings) turned up in the sources checked.
