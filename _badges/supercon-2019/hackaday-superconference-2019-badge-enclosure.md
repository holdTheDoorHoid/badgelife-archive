Tina Belmont (working with Sprite_tm) designed this 3D-printed enclosure for the Hackaday Superconference 2019 badge, an FPGA-based badge built around a cartridge slot for swappable add-on games and demos. The case wraps the badge's PCB in a two-piece plastic shell, using clear/transparent PLA light pipes to carry the badge's onboard LEDs to the surface and natural PLA for the body, D-pad, and buttons. A separate door piece covers the cartridge port while still allowing cartridges to be inserted and swapped.

The design was shared as an open project rather than sold: the GitHub repository includes STL files for each printed part (main body, D-pad, button, cartridge body) along with the full Fusion 360 source model, so anyone with the badge could print their own copy. Print times ran from roughly 9 to 20 hours per part depending on print settings, and Belmont invited other builders to share photos of their own prints.

## Make your own

Print the STL files from the [GitHub repo](https://github.com/softegg/Hackaday-Supercon-2019-Badge-Enclosure) (Main Body Top, D-Pad, Circle Button, and Cartridge Body), using clear/transparent filament for the light-pipe sections and any opaque filament for the rest. The repo's Fusion 360 `.f3z` file is available if you want to modify the design before printing.
