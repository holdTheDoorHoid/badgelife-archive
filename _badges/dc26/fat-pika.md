Fat Pika is a Pikachu-themed Shitty Add-On (SAO) that TwinkleTwinkie built for DEF CON 26 in 2018, describing it as a "kid-friendly" companion piece to release alongside their other DC26 SAO, Krusty the It. The board uses a yellow PCB with black solder mask and black silkscreen, lit by red OSRAM TOPLED (LS T776-P2S1-1-Z) LEDs left over from a previous badge redesign.

TwinkleTwinkie ordered a run of 50 Fat Pika boards (alongside 100 units of another project in the same PCB order). The Hackaday.io project page does not state a sale price, quantity sold, or distribution method, so those fields are left unfilled.

## Make your own

TwinkleTwinkie released the full KiCad project and Gerber files as a zip download from the Hackaday.io project page, making the board straightforward to reproduce for anyone sourcing the same red OSRAM TOPLED LEDs.
