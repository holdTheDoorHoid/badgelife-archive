The Illuminati Badge is a badgelife item attributed to the maker known as _kredence (Kredence on
X/Twitter), associated with DEF CON 26 (2018) on the community badge-tracking sheet this entry was
imported from. Beyond the maker's X/Twitter handle, no independently verifiable source could be
found describing the badge's design, electronics, price, or distribution — the profile page is a
JavaScript single-page app that could not be read as text by the tools available, and web searches
for the maker's name alongside "illuminati badge," "badgelife," "SAO," and DEF CON turned up only
an unrelated company also named Kredence.

The sheet notes that this badge is distinct from a separate "DC27 Illuminati badge" by the same
maker, implying a possible two-year series, but that claim could not be corroborated here.
