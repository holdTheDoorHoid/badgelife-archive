Mr. Robopoly SAO is a shitty add-on (SAO) made by Harbinger LTD, trading as AwkwardAI on Tindie, mashing up the Mr. Robot mask with the Monopoly Man's top hat and monocle. It was one of the maker's earliest badge-making projects, produced for DEF CON 26 (2018) and, per the Tindie listing, compatible with "Defcon 2016 badges and newer," meaning it also worked with DEF CON 27 badges -- hence the "original DC26/27 version" name distinguishing it from a later 2020 refresh.

The SAO was sold fully assembled and tested for $10 in a limited run of 100 units on Tindie. No sources describe an onboard microcontroller, LEDs, or display, so it is likely a simple passive board rather than an electronically active one, though this archive leaves those fields empty since no source states it directly. The Hackaday.io project page for "The Harbinger Shitty Add-on Badges" credits the schematic to bbenchoff's SAO guide and describes it as part of a broader set of shitty add-ons the maker released around that time.

Harbinger LTD went on to release an updated "Mr. Robopoly 2020" SAO on the SAO v1.69bis standard for DEF CON 28, which is a distinct product from this original version and would warrant its own archive entry.
