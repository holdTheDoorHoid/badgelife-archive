The community sheet for DEF CON 32 (2024) lists Cyber Circuitry as a maker but gives no product name, description, or other details for that year's badge or SAO.

Cyber Circuitry LLC (maker Jeremy Wasson, GitHub handle darthdebugger) is the same team behind the 2023 "Prismatic Shard" SAO for DEF CON 31 — see that separate entry. As of both the current site and a Wayback Machine snapshot taken July 29, 2024 (just before DEF CON 32), their storefront still shows only the Prismatic Shard, marked sold out, with nothing new for 2024. No DEF CON 32-specific product could be confirmed from the sources checked, so this entry is left as an unknown listing rather than guessing what, if anything, they brought that year.
