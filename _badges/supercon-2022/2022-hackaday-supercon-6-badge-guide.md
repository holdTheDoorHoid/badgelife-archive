This Hackaday.io project is an educational guide, not a standalone badge or SAO. It walks new owners of the 2022 Hackaday Supercon (Supercon 6, November 2022) badge through programming its onboard 4-bit CPU — a deliberately retro design by Voja Antonic with 10 general-purpose registers, 31 opcodes, front-panel buttons for direct binary input, and an LED matrix that shows register and system state. The guide was assembled by a Hackaday team (credited as Lutetium, Tom Nardi, Elliot Williams, Al Williams, and Bogdan Roșu) as six step-by-step lessons covering binary input basics, arithmetic operations, program flow (branches, loops, jumps), and hardware I/O.

It links out to a companion GitHub repository of badge tools (an assembler, emulator, and example programs) and a browser-based assembler hosted at cloud.wd5gnr.com, plus an official technical documentation PDF. The physical badge itself already has a separate entry in this archive (`supercon-2022-badge-for-supercon-6-november-2022`); this guide page documents how to use that hardware rather than describing a different product.
