The Minibadge Name Tag is a wearable case, designed by RuShan for SAINTCON 2025, that holds and displays a single SAINTCON minibadge. It is a custom 3D-printed enclosure with a hot-swappable name plate, so the wearer can change the printed name (or show off a different minibadge) without rebuilding the whole tag. The kit, as listed, includes the case, name plate, mounting magnets, and a battery, and is fastened to clothing magnetically.

It has no microcontroller or firmware of its own — it is an accessory for displaying an existing minibadge rather than an electronic badge in its own right. RuShan published an assembly/soldering walkthrough video for it, and it is catalogued as "Super Rare" and "Other" category on minibadge.wiki, the community-run SAINTCON minibadge database, which is the only source found for this item.
