This entry and `bsides-las-vegas-2017-tikibadge` appear to describe the same physical badge, reported by the archive's discovery sweep from two different sources under two different names. Hackaday's DEF CON 25 hardware-badge roundup calls it "Life's A Breach / Tiki badge," credits it to a BSidesSF team of "[bon] and [redacted]," and describes a 3D-printed housing around a PCB with blinky LEDs, batteries, and silkscreen art, plus a vellum diffuser standing in for the eyes. The maker's own GitHub repository, under the handle r3dct3d ("redacted"), titles the same tiki-themed project simply "TikiBadge" and calls it a "DC25, BSidesLV-2017 hacker badge" — tying it to DEF CON 25 and BSides Las Vegas rather than BSides San Francisco.

Because the research guide directs preferring a maker's own words over press coverage, this entry's event has been corrected from BSides San Francisco 2017 to BSides Las Vegas 2017 to match the maker's repo and the sibling entry. The repo holds a PCB schematic/layout PDF, a photo of the assembled board, and STL files for 3D-printed tiki mask, torch, and lotus overlay pieces, but no firmware was ever published despite the README promising it "shortly" — so microcontroller, LED type/count, display, and power details remain undocumented and are left blank here.

Given the overlapping maker credit ("redacted"), matching tiki theme, and matching 2017 DEF CON season, this is treated as a likely duplicate of `bsides-las-vegas-2017-tikibadge` rather than a second, separate badge.

## Notes merged from the duplicate entry "TikiBadge"

TikiBadge is an independent, tropical/tiki-themed hacker badge made by a creator going by "redacted" (GitHub handle r3dct3d, Twitter/X handle @notyep) and given out at DEF CON 25 and BSides Las Vegas in 2017. The maker's GitHub repository holds a PCB schematic/layout PDF, a photo of the assembled board, and a set of STL files for 3D-printed overlay pieces shaped like a tiki mask, a torch, and a lotus flower, suggesting the badge's enclosure or face was meant to be built up from printed parts on top of the PCB.

No firmware was ever published: the README promises code "shortly," but the repository contains only hardware files. As a result, core electronics details — microcontroller, LED count/type, display, connectivity, and power source — are not documented anywhere and are left blank here rather than guessed.

The README also notes that some attendees who picked up a badge at DEF CON or BSidesLV received "pre-done" (unfinished) units, and the maker asked recipients to get in touch so those could be completed or replaced. A Hackaday DEF CON 25 badge roundup separately describes a very similarly named "Life's A Breach / Tiki badge" as a BSides San Francisco 2017 badge from makers "[bon] and [redacted]" — the shared "redacted" credit and tiki theme make it likely this is the same project being described from two different angles, but the maker's own README explicitly ties this repo to BSidesLV/DC25, so the entry's event has been left as BSides Las Vegas 2017.
