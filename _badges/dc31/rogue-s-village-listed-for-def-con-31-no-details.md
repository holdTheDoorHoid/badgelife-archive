Rogues Village is a DEF CON village run by Four Suits Co., a Los Angeles-based "experimental magic collective" that explores social engineering, physical security, and sleight-of-hand as security-adjacent skills. The group ran an in-person or hybrid village at DEF CON 27 through 30, including an Inter-Village Badge collaboration with Monero Village for DEF CON 28 and a text-based "Rogues Adventure Game" tied to that badge.

The community badge sheet carried a row for Rogue's Village at DEF CON 31 (2023) with no further details, which is why this entry exists. Checking the maker's own archive page turned up the answer: Rogues Village announced it would not be participating in DEF CON 31, citing changes to DEF CON's village policies. No badge, SAO, or other physical item was produced under the Rogues Village name for DEF CON 31 — the sheet listing does not correspond to an actual item.

For context, Rogue's Village did sell a physical item the year before: a poker-chip-shaped badge at DEF CON 30 (see the separate `dc30-poker-chip-badge` entry), sold through foursuits.co for $10.
