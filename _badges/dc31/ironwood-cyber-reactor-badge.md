Ironwood Cyber, a Fort Worth, Texas cybersecurity company founded in 2021 by former Lockheed Martin Fellows Dr. Aaron Estes and Ethan Puchaty, made this reactor-themed badge for DEF CON 31 as their second annual hardware badge (internally the "Mark II"), following the DEF CON 30 Tron Badge. It paired with a mobile app, a serverless backend, and a social game with a mini-CTF run by a GameMaster, built by a small crew: kimboslice, notthatguy, and joehacksalot on PCB and embedded software; n0decaf on embedded software; Shiloh on the mobile app, serverless cloud, and social game/mini-CTF; and LeetPanda and Spaghetti Code on the website.

Roughly 250 units were made, with about 175 given away at DEF CON 31 and Black Hills InfoSec's Camp BHIS mini-challenge events; the rest appear to have gone out through small-batch charity fundraiser auctions on RallyUp, including one benefiting BSides Orlando sponsorship. Unlike the prior year's Tron Badge, whose KiCad schematics are public, this badge's schematics and source code were never published -- the original badge.life page marks both as TODO, and no matching repo exists in the Ironwood-Cyber GitHub org today. This entry is a duplicate of dc31-arc-reactor-badge-mark-ii, which carries the same badge under its maker-chosen name with fuller company background.
