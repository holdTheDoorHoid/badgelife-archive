[Nyan Pirate](https://github.com/securelyfitz/nyan-pirate) is a 2014 open-hardware project by GitHub user securelyfitz that reskins the [Bus Pirate](https://en.wikipedia.org/wiki/Bus_Pirate) — a well-known open-source universal serial-interface debugging tool — with a Nyan Cat theme. The repository holds Eagle schematic and board files, Gerbers, a bill of materials, and a COPYING.TXT license, indicating the hardware design is freely shared, but there is no written README beyond the title and no photos of an assembled unit.

This is a hobbyist tool board, not a conference badge or SAO: nothing in the repository ties it to a specific hacker convention, year, or distribution event, and it shows no badge-like features (no MCU beyond whatever a standard Bus Pirate build uses, no LEDs, no display, no SAO header described). It does not belong in the badge/SAO catalog as an "item" entry.
