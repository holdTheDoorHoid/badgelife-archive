This entry, sourced from a link list, pointed to a GitHub repository
(`hamster/SAINTCON`) rather than a page for one specific badge. On inspection
the repository is not a DC801 project and is not a single badge: it collects
several distinct SAINTCON village minibadge PCB projects made in different
years by GitHub user "hamster" -- a 2022 "Circuit Learning Minibadge" for the
Hardware Hacking Community (HHC) village, a 2023 CHC minibadge, and 2025/2026
"Bitstream Hackers" minibadges. Nothing in the repository credits DC801 (the
Salt Lake City DEF CON group) as the maker of any of these.

The 2022 minibadge is the best-documented of the four: its README describes
it as a "Circuit Learning Minibadge" handed out as a kit and assembled at the
Solder Skills Community table, built around a 555 timer with a red/green LED
pair, resistors, and capacitors, paired with a printed circuits workbook for
self-guided learning about basic analog circuits. KiCad source files, a PCB
panel, an assembly guide with build photos, and an assembly video are all
included in the repo for that year.

Because no source ties this to DC801 or to a single named badge, this record
is being marked as not an item rather than researched as one. The four
individual yearly minibadges are flagged below as candidates for their own
entries if a maker or hosting village can be confirmed for each.
