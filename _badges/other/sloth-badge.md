The Sloth Badge is a wearable, coin-cell-powered blinky made by Berlin-based maker davedarko, first posted to Hackaday.io in November 2017 as an entry to a "Coin Cell Challenge." Shaped like a sloth's face, it carries twelve 0805 LEDs of different colors, charlieplexed off a single ATtiny13A so that a full multicolor animation set fits on a tiny, low-pin-count chip. A single button steps through five LED animations and into a low-power sleep mode, keeping the pair of CR2032 cells running for a long time between charges. The design was explicitly conceived as a sloth-themed answer to Pimoroni's Bearables badges, sharing their coin-cell wearable format and menu-driven button interface.

Starting in February 2018, davedarko sold the badge on Tindie as the "Unbearable Sloth Badge," offered either as an unassembled kit or as a hand-soldered, fully assembled unit, in a one-time run of about 60 boards. Reviewers praised the build documentation and LED placement guides. The Tindie listing has since been retired and no longer shows pricing, with davedarko noting in the listing that once the run of 60 sold out, no more would be made; a companion "hair-clip" variant was also listed on Tindie but could not be reached for this write-up. The hardware and firmware are published on GitHub (`davedarko/sloth_badge`), including the animation code, though the specific EDA tool and license used were not confirmed.

## Notes merged from the duplicate entry "sloth badge"

The sloth badge is a wearable, sloth-shaped blinky pin built by Hackaday.io user davedarko and posted in November 2017 as an entry to Hackaday's Coin Cell Challenge, a low-power design contest rather than a physical convention. It runs on an ATtiny13A driving 12 LEDs in a charlieplexed arrangement, with a button-driven menu of animations modeled directly on the menu system used by Pimoroni's Bearables line of badges. The project write-up frames it partly as a technical exercise in power efficiency: the maker reports getting power-down consumption down to roughly 0.1 microamp, a large improvement over the 1.1 milliamp draw he measured on an original Bearables board, achieved by working around some quirks in the ATtiny13A's sleep behavior.

Design files for a REV1 board are published in davedarko's Simple-Add-ons-SAO GitHub repository, including an Eagle schematic and board layout plus a PDF render, though no firmware source file or license was found alongside them at the time of this research, so the project is only partially open source by the archive's standard. There is no indication in the available sources that the badge was ever sold or distributed at scale — it reads as a one-off or small-batch personal project — so pricing, quantity, and distribution details are left blank rather than guessed.
