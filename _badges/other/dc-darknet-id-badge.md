This is an independent, unofficial ID badge made for the "DC Darknet" community at DEF CON 22 (2014), shared publicly on OSHWLab under the user handle "feather." The OSHWLab listing itself is minimal — no bill of materials, no generated board preview, and no attachments — so the specific hardware on this particular PCB (microcontroller, LEDs, connectivity) could not be confirmed from the primary source.

Press coverage from the following year describes an annual, unofficial "DEF CON DarkNet Badge" made by badge designers known as Smitty and Krux: an Arduino-based badge that exchanges identifiers with other badges over infrared when pointed at one another, sold on-site as a $25 kit that has reliably sold out within about 90 minutes each year it has been offered. That coverage explicitly calls the 2015 (DEF CON 23) badge "very similar to last year's," implying a DEF CON 22 predecessor existed — which this listing's title matches. However, nothing found ties the OSHWLab uploader "feather" directly to Smitty or Krux, so this write-up treats that as a plausible but unconfirmed connection rather than a fact, and no technical fields were filled in based on it.

DEF CON 22 predates the oldest event catalogued in this archive's event list (DEF CON 24, 2016), so this entry remains filed under "other" rather than a dedicated DC22 event id.
