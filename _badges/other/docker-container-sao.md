The Docker Container SAO is a Shitty Add-On sold individually on Tindie by maker Alee (Tindie handle alee97422), first seen listed in June 2024. It runs on an ATtiny85 microcontroller driving a set of blue LEDs through current-limiting resistors, and its PCB uses JLCPCB's full-color silkscreen process to print a tie-dye pattern across the board rather than a conventional solid solder mask.

Unlike Alee's other credited badges in this archive (the DEF CON 32 TPB Badge, DEF CON 33 cRab, and DEF CON 34 Breadbadge), this listing does not tie the SAO to a specific convention or year — it reads as a standalone Tindie storefront item rather than a con-specific badge, and it was priced at $10.98 when last observed. No hardware files, firmware, or build documentation were found alongside the listing.
