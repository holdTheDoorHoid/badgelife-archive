The "Shitty Add-Ons" (SAO) Hackaday.io project is the community hub for the open SAO connector standard used across the hacker-conference badge scene, not a single badge or product. It was started in February 2018, led by Hackaday's Brian Benchoff, building on earlier badge-add-on precedents such as the 2016 Queercon badge hats and 2017 DEF CON Brain Slug add-ons. The page defines connector types, pinouts, voltage, and mechanical dimensions so add-ons made by one designer plug into badges made by another.

The spec has gone through revisions, most notably V.1.69bis (also called SAO.69), released in 2019, which introduced a six-pin 2x3 connector supporting power, I2C, and GPIO for addressable LEDs, while remaining backward compatible with the original four-pin design. The project also hosts reference hardware, including the "Shitty Add-On Totem," a simple power-distribution board with battery holders and four headers for mounting several add-ons at once.

Because this page documents a standard rather than a purchasable badge or SAO, it is marked as not an item for this archive; no event, maker, or product fields apply.
