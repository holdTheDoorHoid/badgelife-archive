"BGD" (Badges and Gadgets of Defcon) is a GitHub repository maintained by the user DefconParrot that catalogs and links to source material for a range of DEF CON badges and gadgets across multiple years, rather than being a single badge or SAO in its own right. It functions as a personal index/archive — pointing to items such as the DEF CON 29 Tor Project badge, the DCZia Electric Sampler, the DEF CON 18 badge, and the DC31 "The Future Will Prevail" badge — with source code links and short notes rather than original hardware of its own.

Because it is a reference collection rather than a distinct badge, it does not fit the archive's per-item schema and has been marked `not_an_item`. Any of the individual badges it references that are not already catalogued here would be better added as their own entries, sourced from each badge's own project page.
