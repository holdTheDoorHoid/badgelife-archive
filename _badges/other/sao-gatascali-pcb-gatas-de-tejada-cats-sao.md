"SAO_GatasCali_PCB" is a cat-shaped SAO (Simple/Shitty Add-On) PCB designed by Nick Velasquez, an IoT developer and electronic engineer who publishes hardware projects under the GitHub handle electronick-co (and the studio name DeepSea Developments). Per the repository's own one-line description, it is a "PCB design of the SAO ... fron the cats from Cali colombia (Gatas de tejada)" — suggesting it was made for or named after a cat-themed maker/hacker community or group nicknamed "Gatas de Tejada" in Cali, Colombia.

Beyond that description, the project is effectively undocumented: the GitHub repository was created in August 2026 but has never had any files pushed to it — no schematic, Gerbers, BOM, firmware, README, or photographs. No independent write-up, storefront listing, or social post about the board could be found, and the maker's personal site (electronick.co) does not mention it, though it does describe a separate, unrelated 2025 event-badge project. As a result almost every technical and distribution field here is unknown; this entry may need revisiting if and when the maker publishes actual project files.
