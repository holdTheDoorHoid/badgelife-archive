"ConCrud: Zelda Rides" is a browser-playable tower-defense game, not a physical badge or SAO. It was made by a creator known as Zelda for GameChangers AI, a nonprofit focused on hands-on AI/electronics education for young people, as an activity for DEF CON 34 attendees. The game runs in a web page with keyboard controls (number keys to pick towers, WASD/arrows to move a cursor, N to start a wave, P to pause) and its maps are modeled on the Las Vegas Convention Center, the DEF CON 34 venue.

This entry was created by an automated sweep that mistook the game's project page for a hardware listing because it was linked alongside GameChangers AI's actual conference hardware. That hardware is the "Friend or Foe" badge, an open-source ESP32-S3 RF-awareness wearable, which already has its own entry (dc34-friend-or-foe-badge) in this archive. No badge, SAO, or other physical item corresponds to the title "ConCrud: Zelda Rides" itself.
