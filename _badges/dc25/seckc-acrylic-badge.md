SecKC, the Kansas City–based infosec meetup group, brought two different badges to DEF CON 25 in 2017: a circuit-board devboard badge built around a SparkFun module, and this simpler edge-lit acrylic badge. The acrylic version came about because the group could not finish manufacturing enough of the circuit-board badges in time for the con, so members showed up with these edge-lit acrylic pieces as a fallback for attendees who would otherwise have gone without one.

Little beyond that has surfaced about the acrylic badge specifically — no maker photos, pricing, or a confirmed quantity were found, and it does not appear to have its own design-file repository (the SecKC GitHub project covers the electronic devboard badge, not this one). It should not be confused with that other, more fully documented SecKC badge from the same year, which is tracked separately in this archive.
