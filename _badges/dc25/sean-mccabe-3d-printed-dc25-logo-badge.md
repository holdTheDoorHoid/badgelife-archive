## Notes merged from the duplicate entry "Sean McCabe's 3D Printed DEF CON 25 Badge"

Sean McCabe (Twitter/X handle @SeanLeftBelow) brought a 3D-printed badge to DEF CON 25 in 2017 shaped like that year's con logo, where the "2" and "5" of "25" form a skull with a pair of keys standing in for crossbones. A custom PCB on the back holds a single RGB LED driven by an ATtiny85 and powered by a coin cell.

Hackaday's DEF CON 25 badge roundup is the only source found for this item; it noted design files were available on McCabe's GitHub repo, but that account (github.com/seanleftbelow) returns a 404 today, so hardware/firmware files, price, and quantity could not be confirmed independently. No storefront listing or Hackaday.io project page was found.

Note: the original sweep's title, "Tindie 3D Printed DEF CON 25 Badge," misleadingly combines this badge with a different one described in the same article - an "Ohm the Tindie dog" solder kit (self-blinking LEDs, coin cell, custom PCB) that Tindie staff Jasmine Brackett and Shulie Tornel handed out, built from a Brian Benchoff PCB design. Those are two unrelated items; this entry covers only Sean McCabe's badge.
