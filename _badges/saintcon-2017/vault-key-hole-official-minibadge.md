One of nine official minibadges issued for SAINTCON 2017, distinct from the community-made "unofficial" minibadges tracked on a separate page of the same badge documentation site. It is named "Vault - Key hole," suggesting a lock/vault theme, but the only source found — the conference's own minibadge list — gives no further description, no maker attribution, no photo, and no technical details, so most of this entry remains unfilled.

The list groups it with other track- or theme-tied official minibadges from the same year (Jupiter, Luke, Protoboard, Lock pick, Speaker, Alien Head, Block S, Hackers Challenge), several of which map to known SAINTCON villages or roles (HHV to the hardware hacking village, LPV to the lock pick village). That pattern makes it plausible the Vault badge was tied to a security- or lockpicking-adjacent track rather than made by an individual hobbyist, but no source confirms this directly, so it is noted here only as a caveat rather than recorded as fact.
