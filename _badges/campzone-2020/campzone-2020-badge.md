The CampZone 2020 badge is documented on Badge.Team's platform docs alongside the group's other event badges (SHA2017, CampZone 2019, Disobey, HackerHotel), sharing the same MicroPython-based ESP32 badge firmware and API set: a keypad, a display, an audio/sound mixer with speech synthesis, Wi-Fi and MQTT networking, USB/Bluetooth HID, MIDI output, and capacitive touchpads. Badge.Team credits volunteer Tom Clement for the CampZone 2020 edition.

Beyond the module list, the maker's own documentation gives no further specifics — no stated chip part number, LED count, display size, battery, price, or production quantity — and no badge-specific hardware repository could be found in the badgeteam GitHub org (unlike CampZone 2019, which has its own `cz19-badge` repo). The only image on the docs page is a PCB-outline SVG generated by KiCad's PCBNEW, not a photo of an assembled badge, and it isn't a format this archive's image tool can save. It is unclear whether this badge was physically produced and distributed for CampZone 2020 or documents a firmware/software configuration without confirmed independent hardware.
