No maker page, GitHub hardware repo, Hackaday.io project, or storefront for a physical GHV badge turned up in this pass, and the village's own site has no shop, store, or badge page. It is possible the badge never moved past the rumor stage, or that it exists but simply isn't documented publicly (or was only shared inside their Discord). This entry is left as rumored/unknown pending a firsthand sighting or a maker post that actually shows the hardware.
