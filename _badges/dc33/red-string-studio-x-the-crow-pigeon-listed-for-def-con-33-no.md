The community badge-tracking sheet for DEF CON 33 (2025) lists "Red String Studio x The Crow & Pigeon" as an expected maker, but the row carries no title or details. Research turned up why: this is the same duo behind [The Duck Badge](/dc32-the-duck-badge) at DEF CON 32 (2024), a quacking electronic badge sold in a "flock." Their project site, hackthequack.com, states plainly that the team "migrated south early" that year and could not make it to DEF CON 33, adding that they hope to return in the future.

In other words, they were anticipated by whoever compiled the sheet — likely because they had shown up the year before — but did not actually attend or release anything for DEF CON 33. No badge, SAO, or other item exists from this maker for this event.

This entry is kept as a record that the sheet row does not correspond to a real 2025 product, rather than deleted, so it doesn't get re-researched from scratch later. If Red String Studio x The Crow & Pigeon are confirmed to have shown up after all with something undocumented here, this entry should be updated and un-cancelled.
