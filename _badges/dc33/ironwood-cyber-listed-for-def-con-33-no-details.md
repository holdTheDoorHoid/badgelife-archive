Ironwood Cyber (also credited as "Ironwood Cyber Team") is a maker group with badges in
this archive for three consecutive DEF CONs: the Tron Badge at DC30 (2022), the Reactor
Badge (Arc Reactor Mark II) at DC31 (2023), and the Crest Badge at DC32 (2024). The
community sheet for 2025 lists them again as an expected maker for DEF CON 33, but with
no title, description, or links attached to the row.

No trace of a DC33 badge could be found. The team's GitHub organization
(github.com/Ironwood-Cyber) holds only one badge repository, the DC30 hardware share;
its more recent repositories are product documentation and code templates. The two
Discord invites tied to the DC31 and DC32 badges both now open a server titled
"SplinterOps (Previously: IronwoodCyber SummerGames)", with no visible mention of a 2025
badge. The ironwoodcyber.com domain is now home to a cybersecurity company selling an
autonomous penetration-testing platform called Enlight; it uses the same @IronwoodCyber
social handle as the badge team and hosts its documentation under the same GitHub org
that stores the DC30 badge hardware, but says nothing about DEF CON. Whether Ironwood
Cyber actually brought a badge to DC33, and if so what it was, remains unconfirmed.
