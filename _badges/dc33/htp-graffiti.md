HTP Graffiti (sold by the maker as "Hack the Planet SAO") is an all-analog SAO by HogFillet: a 555 timer clocks a 10-bit ripple counter, and eight of the counter's outputs drive eight LEDs that shine up through holes drilled into "Hack the Planet" graffiti-style artwork on the board. An onboard trimmer potentiometer sweeps the clock speed from a slow, heartbeat-like pulse to a fast strobe. There is no microcontroller and no firmware.

A second feature added for this edition is a button wired to short either the odd or the even GPIO pin of the host badge's SAO header, with effects that depend entirely on how the host badge's designer handled that pin — the maker describes it as intentionally unpredictable and makes "no promises." The board was sold through HogFillet's Uberflux storefront at $24, with 31 made (10 still listed as available as of the last check), and was also offered for in-person pickup or trade at DEF CON.

Despite being imported from the DEF CON 33 (2025) community sheet, the maker's own GitHub repository and storefront listing both label this piece as a DEF CON 34 (2026) SAO; no separate DC33 edition was found. This is noted above rather than acted on, since moving the entry to a different event folder was outside the scope of this pass.

## Make your own

The hardware is fully open (CC0-1.0): the GitHub repo (linked above) contains the complete KiCad schematic and PCB files for the "Black PCB DC34" board. Since the circuit is pure analog (555 timer + ripple counter + LEDs), no firmware or build toolchain is needed — just the KiCad files and standard through-hole/SMD assembly.
