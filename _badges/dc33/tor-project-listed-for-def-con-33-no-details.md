The community badge sheet lists the Tor Project as an expected maker/presence at DEF CON 33 (2025), but with no further detail. The Tor Project's own event post for DEF CON 33 confirms it had a booth at the conference and invites visitors to "check out new Tor merch," without describing any electronic badge or SAO.

In past years a community hardware maker known as Seeess produced a recurring line of Tor-branded electronic SAOs and badges (documented on GitHub as Defcon-Tor-27, -29, -30, -31 and -32; there is no DC28 entry). The DC27 README says those boards were handed to Tor to sell as a fundraiser, and the DC32 README says the "mini-badge" SAO was sold at the Tor vendor booth; the line also included the lie-detector-badge variants. No equivalent "Defcon-Tor-33" project could be found for 2025, so it is unclear whether that series continued, paused, or simply has not been documented publicly yet. Seeess's 2025 project, the Defcon-Tipsy-33-Badge, is not Tor-branded, but its README states that half of its sale profits go to the Tor Project. This entry is left as an unresolved stub pending confirmation of what, if anything, was distributed under the Tor Project's name at DEF CON 33.
