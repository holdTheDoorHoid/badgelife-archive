The F-35 badge was built by Lockheed Martin's Aeronautics Cyber Range (ACR) team and given out free at their booth in the Aerospace Village at DEF CON 33 (2025). It is styled after the F-35 fighter jet and turns the con's usual badge-collecting into a lightweight combat game: each badge has a color display, two side buttons, and a rotary encoder, and uses Bluetooth to detect other nearby badges and an IR transmitter/receiver to "shoot" them. Wearers can set a callsign and a team code (so teammates aren't targeted), enter a "Lethal Interrogate" targeting mode to lock onto another badge, and fire at it with IR to score a kill; a badge that gets hit goes into a "DEAD" state with pulsing red LEDs before respawning after about 20 seconds. Perimeter RGB LEDs and a front-facing LED communicate state (green when you can shoot, red when you're a valid target, red breathing while dead), and the badge can join WiFi to check for and install firmware updates.

The project was credited to three people on the ACR team: "risky" (software), "Nyquist" (hardware), and "Broske" (3D design). The GitHub repo (github.com/riskyblooky/f35badge) is presented as a public user guide rather than a full open-source release -- it holds the README and a few branding images (Lockheed Martin and ACR logos, a DEF CON 33 logo, and an unofficial team logo) but no schematics, firmware source, or bill of materials, so it isn't possible to confirm the specific MCU, LED count, display size, or battery from what's published. No independent press coverage of the badge was found during this research pass; the write-up above is drawn entirely from the maker's own README.
